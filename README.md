# 数码医生 DoctorUSB

> U盘上的网管 + 维修工程师 + 离线 AI。插上就能用，不装软件、不删软件、不联网，修完可一键还原。

去朋友/亲戚/同学家修电脑，不用带笔记本、不用联网，一 U 盘搞定：**体检 → 离线 AI 诊断 → 逐项确认修复**。

和黑客 U 盘相反——不偷数据，专门救数据、救电脑。

---

## 特性

| 能力 | 说明 |
|---|---|
| 🩺 一键体检 | 100% 只读，8 大项检测（系统/磁盘/网络/连通性/局域网/端口/恶意广告/系统状态），约 20 秒出报告 |
| 🤖 离线 AI 诊断 | U 盘自带 Ollama + qwen2.5（3B/7B 可选），读体检报告直接给结论和修法，**全程不联网，数据不出 U 盘** |
| 🔧 可逆修复 | 每项修复前先备份到 `backup\` + 逐项确认，自动生成一键还原脚本 |
| 📱 病历卡 | 本地纯计算生成二维码，手机扫码看摘要（无网也能用） |
| 🔍 深检 | 垃圾软件家族/可疑自启追踪（捆绑全家桶重灾区专用） |

## 快速开始

1. 把本仓库的 `数码医生.bat`、`tools\`、`说明书.txt` 放到 U 盘一个文件夹里，再准备 Ollama 便携版与模型（见下文「准备 AI」）
2. 插入 U 盘，双击 **数码医生.bat**
3. 按菜单数字：`1` 体检 → `3` AI 分析 → `2` 修复

```
一句话记住：「先按1查 → 再按3问AI → 最后按2动手修」
```

## 准备 AI（唯一需要动手的部分）

Ollama 程序和模型体积大，不适合放 git。两种方式二选一：

**方式 A（推荐，无需翻墙）**：本仓库 Releases 页面自带 **ollama-cpu-windows.zip**（CPU 通用精简版，约 26MB，免费开源 MIT 协议）——这是从完整版中裁掉 GPU 加速库的最小可运行包，任何 Win10/11 电脑都能跑（无独显也能用，只是慢一点）。下载解压，把里面的 `ollama.exe` + `lib\` 放进 `<U盘>/OllamaU盘/ollama/`。

**方式 B**：官网下载完整版 https://ollama.com/download/windows（约 1.4GB，含 CUDA/ROCm/Vulkan GPU 加速，有 NVIDIA 独显的电脑推荐）

然后准备模型（免费，二选一）：

1. 找一台能联网的电脑，安装 Ollama 官网版
2. 运行：`ollama pull qwen2.5:3b`（8G 内存老电脑）或 `ollama pull qwen2.5:7b`（16G 内存推荐）
3. 把模型目录拷回 U 盘（Windows 上一般在 `C:\Users\<你>\.ollama\models`），放到 `<U盘>/OllamaU盘/models/`

最终目录结构：

```
<U盘>/OllamaU盘/
├── ollama/                # ollama.exe + lib\（从 release zip 解压）
├── models/                # qwen2.5 模型（3b 或 7b）
└── 数码医生/              # 本仓库内容（含 prepare_ai.bat）
```

配好后双击 **prepare_ai.bat** 一键自检，全部 ✅ 即插即用。

> 💡 **完全离线 · 完全免费**：部署后 AI 分析全程不联网、不需要任何 API key、数据不出 U 盘。ollama 和 qwen2.5 都是开源免费软件。

## 修复功能清单（全部可还原）

| 功能 | 治什么 |
|---|---|
| 刷新 DNS 缓存 | 网页打不开先按这个 |

## ⚠️ 杀软误报说明（重要）

修复模块涉及修改注册表/hosts/计划任务，**Windows Defender 等杀软可能将本工具报为 `HackTool`/`Riskware`**（这是同类系统工具的常见误报）。本项目：

- 体检与深检 100% 只读，不修改任何设置
- 修复前必先备份并逐项确认，全程留痕可还原
- 不包含任何绕过安全软件、隐藏痕迹、窃取数据类功能

如遇误报，请将本工具目录加入杀软白名单。源码完全公开，欢迎审计。
